This is a **season-ready club presence** (calendar, lidgeld, GDPR, helpers) in the same price band as a real Belgian starter site (€550–€1,500) and cheaper than a year of Twizzit Hattrick for a 200-member club (~€950 licence + €195 onboard). ## Idea 3 — Peppol Send + Receive Go-Live

**Price:** 2,500 USDC (one-off, week 1)

**Who buys:** Belgian **VAT-registered** entities that still email PDF B2B invoices, or that can **send** but still cannot **receive** structured invoices. Also B2C-only shops that must still **receive** supplier e-invoices. Also fiduciaires who need a repeatable client onboarding pack.

This is a legal category, not a named client:

- Mandate in force **1 January 2026** (FPS Finance / e-invoice.belgium.be).
- Three-month tolerance **ended 1 April 2026** (FPS Finance on Radio 2, reported by Deloitte Legal). Self-billing extra window was to **30 June 2026**.
- UNIZO: PDF by email is not enough; send **and** receive via Peppol.
- Teamleader support: first offence **€1,500**, second **€3,000**, then **€5,000**.
- peppol.nu (post-deadline): many SMEs registered to send but inbound processing is still manual.
- Software itself can be cheap (Accountable / Billit free-or-low; Teamleader Peppol **included**; Let’s Peppol free AP). The paid gap is **go-live**: master data, receive path, first live documents, archive.

**What we ship in one week:**

1. Scope check against the official “who is concerned” tool on e-invoice.belgium.be (client’s KBO / VAT — they paste it; we do not harvest registries).
2. Activate **send and receive** on software they already pay for if possible (Teamleader GROW+, Billit, Accountable, Exact). If they have none, pick the cheapest listed compliant tool that fits volume — we do not invent a new Peppol network.
3. Peppol participant ID from the Belgian KBO scheme (`0208:…`).
4. Master-data pass: legal name, VAT, IBAN, OGM, unit prices, VAT rates. Garbage here is why invoices bounce.
5. One **live outbound** B2B invoice and one **live inbound** (or a documented receive test with the accountant).
6. Seven-year structured-archive SOP (Belgian retention). Dutch one-pager for the boekhouder.
7. Operator: forwards KBO, IBAN, existing software login-or-invite. Does not code. Does not become the accountant.

**Why it is not a 9 USDC toy:** The 9 USDC Solana Invoice page outputs an amount and a QR. Belgian B2B law requires **UBL / Peppol BIS**, not a PDF. Market implementation sits **€500–€5,000** (setup) and **€2,000–€5,000** for a standard connector. Penalties go to **€5,000**. 2,500 USDC is a **compliance go-live**, ~278× the toy.
