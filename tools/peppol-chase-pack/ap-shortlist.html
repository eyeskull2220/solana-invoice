Source of truth (use this, not our snapshot)

  • OpenPeppol certified service providers (list latest updated 21 August 2026 when this pack was built): peppol.org/members/peppol-certified-service-providers
  • Belgian Peppol authority pointer (BOSA): filter the same list by country Belgium or authority BOSA. See digital.belgium.be e-invoicing.
  • OpenPeppol full members list (public websites): peppol.org/members/full-members-list

The FPS Finance “software solutions” page is an end-user software list, not the Access Point registry. This shortlist is APs only.

How this shortlist was built

  1. OpenPeppol certified service providers, snapshot taken 2026-08-26 from the list dated 21 August 2026.
  2. Kept rows with Country/Territory = Belgium, Access Point = AP Certified, Peppol Authority = BOSA.
  3. Kept only names that also publish a public website on the OpenPeppol full members list.
  4. Shortlisted public commercial APs a Belgian enterprise might actually contact. Captive or internal APs (for example a logistics operator that is certified for its own flows) are omitted.
  5. No personal names, no personal inboxes, no phone numbers copied from the registry.
