Werkblad — Google review-URL (geen API)

Wij halen geen Place ID op. U kopieert de link uit Google Maps (Delen) of uit Google Business. Plak hier. Niets wordt naar een server gestuurd.

  1. Open Google Maps in de browser.
  2. Zoek uw zaak. Kies Delen, of de knop voor een beoordeling.
  3. Plak de URL hierboven. Typische vorm: https://search.google.com/local/writereview?placeid=…
  4. Zelfde URL op qr.html voor de toonbanksticker.
