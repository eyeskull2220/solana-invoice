# Belgian BTW invoice

One HTML file for Belgian freelancers. Fill seller and client, add line items, apply BTW, download a standalone invoice.

**9 USDC.** Pay on Solana (USDC only — not SOL, not Base, not ETH, not XRP) to:

`96BT6r5C35cvokdVop8ro4vDtv9zKUxpzrLbXqQbuHk3`

Open `index.html` in a browser. No account. No wallet connect. Copy-address only. Works offline after open.

## Use

1. Pay 9 USDC on Solana to the address above (copy from the page).
2. Fill **seller** and **client** (name, address, optional BE BTW/KBO number).
3. Set invoice number and date.
4. Add line items (description, quantity, unit price excl. BTW).
5. Confirm the BTW rate (default **21%**). Totals update live: excl / BTW / incl.
6. **Download HTML invoice** and send that file.

Placeholders use fake names only (Studio Noord, Client BV).

This is not tax advice. 21% is Belgium’s standard rate; confirm the rate that applies to you.
