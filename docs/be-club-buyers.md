**Date:** 2026-08-26  
**Scope:** research only. No mail sent from this document.  
**Product:** one-shot Dutch static club kit (home, over, agenda, lid worden, contact). Demo: <https://club-site-kit-treasury.surge.sh/>. Price: **900 USDC once**. Buyer gets files and can self-host. No Azure AD, no account, no webshop.

## Criteria

Kept a club only when **all** of the following were true on 2026-08-26:

1. Belgian **club / vzw** in West-Vlaanderen, Oost-Vlaanderen, Antwerpen, Limburg, or Vlaams-Brabant.
2. A **public `info@` mailbox** on a page cited in the Source column. No invented addresses. No personal Gmail / Hotmail / Outlook / Skynet. No `*@mail.zwemfed.be` as the club mailbox.
3. **Old, thin, broken, or missing** public site: Google Sites, static `.html`, volunteer dump, Hostnet/placeholder, exposed installer, or a cheap builder that is not a 2025–2026 WordPress/Elementor/Wix/Webflow/Twizzit rebuild.

## Why a 900 USDC static kit fits these rows

These clubs already run on volunteers. They need five Dutch brochure pages, not a membership SaaS. They already publish an `info@` mailbox, so a contact page can be a `mailto:` without a CMS. A one-file / static kit is a drop-in replacement for Google Sites, Hostnet placeholders, table HTML, and One.com dumps. 900 USDC once is cheaper than a local webshop rebuild and avoids monthly Webhero/Twizzit/WordPress hosting. Files stay with the club.
