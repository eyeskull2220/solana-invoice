# Split Bill

One HTML file. Split a total (optional tip and tax) across N people. Even split or custom amounts. Copy a summary. Download a standalone HTML receipt.

Open `index.html` in a browser. No account. No wallet connect. Nothing leaves the device.

## Use

1. Enter the **subtotal**. Optionally add **tax** and **tip** as a percent or a flat amount.
2. Add **people** (names, or leave the defaults and just use the count).
3. **Even split** assigns every cent so shares sum to the total. **Custom** lets you type amounts; they must sum to the total before you download.
4. **Copy summary** for chat. **Download receipt** saves one HTML file you can send or print.
