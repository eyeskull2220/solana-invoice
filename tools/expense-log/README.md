One HTML file. Add expense rows, keep a running total, download a CSV.

No account. No wallet connect. Nothing leaves the browser.

## Use

1. Open `index.html` in a browser.
2. Fill date, category, description, and amount.
3. Click **Add row**. Repeat as needed.
4. Click **Download CSV**.

Rows stay in this browser until you clear them. Download before you clear.

CSV columns: `date,category,description,amount,notes`.
