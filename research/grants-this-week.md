## Methodology

1. **Direct verification**: Every program was visited on its official page on 2026-08-25.
2. **Inclusion criteria**: A program appears in "Apply Now" only if it is open, has stated funding, and accepts proposals at this time.
3. **Exclusion transparency**: Every checked program that did not meet inclusion criteria is listed above with its official URL and the specific reason for exclusion.
4. **No invented listings**: Closed or unverifiable programs are never placed in the apply-now list.
5. **Currency verification**: Where the official page does not state a payout currency, the program is flagged and excluded.
6. **Timeline honesty**: No program is described as paying faster than its official documentation states. None of the listed programs promise a decision or payout before 2026-08-31.

---

## Key Takeaway

Only one program — **Filecoin Documentation Enhancement Grants** — is actionable this week. All others are closed, empty, lack stated funding, or impose requirements (KYC, identity verification) that delay or prevent immediate application.
