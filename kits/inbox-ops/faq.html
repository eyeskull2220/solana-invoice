PDF invoices and Peppol

B2C PDF-by-mail is still allowed. If you are a private person (not a VAT-registered business), Studio Noord can send a PDF or this HTML factuur by mail. That remains a usable invoice for B2C.

B2B PDF is NOT a legal invoice since 1 Jan 2026 (Peppol). If you are a Belgian VAT-registered business, a PDF or HTML file is not a legally valid invoice. Structured e-invoicing via Peppol is required.

We do not make them compliant. Studio Noord does not run a Peppol Access Point. We do not send live Peppol documents. If you need a legal B2B e-invoice, use your accountant or a certified Peppol Access Point. This pack will not do that for you.

Hoe ziet het voorbeeld eruit?

Belgian layout: seller, client, sequential number, date, due date, line items, 21% BTW unless a different rate applies. Demo: Studio Noord → Client BV. Open het voorbeeld and download a standalone HTML file.

That file is a human-readable copy. It is not tax advice. Confirm the BTW rate that applies to the work.
