## Use

Open `index.html` in a browser.

1. Paste JSON, or drop a `.json` file.
2. **Pretty** (2-space indent) or **Minify**.
3. Copy or download the result.

Invalid JSON shows a parse error. Nothing is uploaded. JSON never leaves the browser.
