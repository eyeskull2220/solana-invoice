# Waitlist

One HTML file. 49 USDC. Offline waitlist landing page generator.

Type the product name, headline, and the inbox that should get signups. Download a self-contained landing page. Visitors join with their email app (`mailto`). Nothing is posted to a server.

No account. No wallet on the generated page. Works offline.

## Use

1. Open `index.html` in a browser. No server required.
2. Fill product copy and the destination email.
3. Preview the page. Optional: ask for a name, pick paper or ink.
4. Download `waitlist.html`. Host it anywhere or send the file.

When someone joins, their mail app opens a draft to your inbox with the signup line. If `mailto` is missing or the message is too long, they can copy the signup instead.

## What it does not do

- Does not store emails on a server
- Does not connect a wallet
- Does not trade
